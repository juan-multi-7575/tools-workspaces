# Generic multi-tool platform, not a TTS/audio-training platform

The product is a general media-tool platform, not a TTS dataset builder or audio-training-focused application. TTS-oriented concepts (voices, model types, training handoff, corpora) are explicitly out; the five tools are positioned as generic utilities. This deliberately deviates from the origin of the idea dump, which framed the same catalog as a decomposed TTS pipeline.
